# 🧮 Modern Calculator

A clean, responsive calculator built using **HTML**, **CSS**, and **Vanilla JavaScript**. It provides a smooth user experience with keyboard support, modern glassmorphism UI, real-time expression display, and accurate arithmetic calculations.

---

## ✨ Features

- ➕ Basic arithmetic operations
  - Addition
  - Subtraction
  - Multiplication
  - Division

- 🖥️ Modern Glassmorphism UI
- ⌨️ Full keyboard support
- 🔄 Real-time expression display
- 🧹 All Clear (AC)
- ❌ Clear current entry (C)
- ⌫ Backspace support
- 📱 Fully responsive design
- ⚡ Fast and lightweight
- 🚫 Division by zero error handling

## 🎯 Features Overview

### Basic Operations

Perform standard mathematical calculations:

- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)

---

### Editing Functions

- **AC** – Reset the calculator completely.
- **C** – Clear the current input.
- **⌫** – Remove the last entered digit.

---

### Keyboard Shortcuts

| Key | Action |
|------|--------|
| 0–9 | Enter numbers |
| + | Addition |
| - | Subtraction |
| * | Multiplication |
| / | Division |
| . | Decimal point |
| Enter | Calculate result |
| = | Calculate result |
| Backspace | Delete last digit |
| Esc | Clear calculator |
