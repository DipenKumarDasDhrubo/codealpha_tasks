# 🎵 Nightshift – Vinyl Style Music Player

A modern, responsive **vinyl-inspired music player** built with **HTML, CSS, and Vanilla JavaScript**. It features a realistic animated vinyl record, playlist management, local audio playback, online audio streaming, and a beautiful dark-themed interface.

![Nightshift Preview](preview.png)

> Replace `preview.png` with your project screenshot (the one above).

---

## ✨ Features

- 💿 Animated spinning vinyl record
- 🎵 Built-in demo playlist
- ▶️ Play / Pause / Previous / Next controls
- ⏩ Interactive seek bar
- 🔊 Volume control
- 🔁 Autoplay toggle
- 📂 Import songs from your device
- 🌐 Stream music from direct audio URLs
- 📃 Dynamic playlist
- 🗑️ Remove songs from playlist
- ⌨️ Keyboard shortcuts
- 📱 Fully responsive layout
- ⚡ Built using Vanilla JavaScript

## 🎧 Features Overview

### 🎼 Music Playback

- Play & Pause music
- Previous / Next track
- Seek through songs
- Adjustable volume
- Autoplay support

### 📂 Device Music

Upload one or multiple audio files directly from your computer.

Supported formats include:

- MP3
- WAV
- OGG
- AAC
- M4A

### 🌐 Online Streaming

Paste a direct audio URL such as:

```
https://example.com/song.mp3
```

The player will stream it instantly.

> **Note:** Spotify, Apple Music, YouTube Music, and similar services cannot be streamed directly because they do not provide public audio file URLs.
